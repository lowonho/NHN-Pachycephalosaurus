## 엑셀에서 수정하기

- `01_sfx_priority.csv`: 중요도순 효과음 목록. 게임 열을 필터링하면 각 게임의 작업 순서가 됩니다.
- `02_bgm_inventory_plan.csv`: 보유곡 청취부터 하고, 부족한 게임만 새로 제작하도록 정리한 목록입니다.
- 두 CSV는 한글용 UTF-8 BOM입니다. 엑셀에서 바로 열거나 데이터 → 텍스트/CSV에서 UTF-8로 불러오세요. 필터와 색을 유지하려면 열고 나서 `.xlsx`로 저장하면 됩니다.
- ‘진행 상태’, ‘선택한 음원 URL’, ‘제작자 및 이용조건’, ‘내 우선순위’, ‘메모’를 수정하세요. 상태 추천값은 미착수 → 후보 확보 → 편집 중 → 게임 테스트 → 확정입니다.
- 전체순서는 작업용 정렬값입니다. 같은 중요도 안에서는 테스트 결과에 맞춰 바꾸면 됩니다. 권장 길이와 BPM은 제안값입니다.

## 이번 순서

1. **기존 BGM 6곡 청취**: 메인 외 다섯 곡의 사용처를 먼저 적습니다. 파일명으로 두쫀쿠/특정 밈에 임의 배정하지 않았습니다. 제외 게임용으로 밝혀진 곡은 해당 용도로 남겨두세요.
2. **첫 효과음 묶음 6개**: 공통 시간 손실 충돌·성공·실패·시간 경고, E4 누적 가속 탭·브레이크. 이 묶음으로 반복 조작의 음량과 귀 피로 기준을 잡습니다.
3. **남은 P0 12개**: E8 연결/해제 → E5 발사/명중 → E7 딸깍/정지 → E2 점프/균열 → E1 반전 → E10 점프/정답/오답. 모두 게임 규칙을 소리로 알려주는 항목입니다.
4. **P1 16개**: 바람·재질·당김·활주 등 움직임을 살립니다. 핵심 효과음이 들리는 상태에서 기존곡을 배정하고, 우선 E4/E8/E7의 빈 BGM 용도를 채웁니다.
5. **P2 6개와 나머지 BGM 후보**: 환호와 추가 연출을 검토합니다. 플레이가 시끄러워지거나 기존 소리로 충분하면 보류하세요. 게임마다 새 BGM 한 곡씩 만들 필요는 없습니다.

## 이름과 납품 규칙

- CSV의 ‘효과음 확정명’과 ‘납품 파일명’을 기준으로 맞춥니다. 예: `sfx_e4_accel_tap.wav`, `sfx_e5_target_pop.wav`. 후보를 찾는 중에는 확정명은 유지하고 URL/메모를 바꿉니다.
- 효과음 원본 납품은 WAV, 48 kHz, 16 또는 24 bit로 통일하는 안입니다. 단발은 앞 무음을 잘라 반응을 빠르게 하고, 시작/끝에 짧은 페이드를 넣습니다. 루프는 이어지는 경계에서 클릭/끊김을 확인합니다.
- 현재 파일 구조에 맞춘 신규 제안 경로는 `sounds/sfx/`와 `sounds/bgm/`입니다. 실제 폴더 생성/오디오 연결 시에는 실행 중인 Archive 재생기를 기준으로 적용합니다. `assets/audio/`를 적은 별도 manifest는 비어 있어 이름만 등록한다고 재생되는 상태가 아닙니다.
- 기존 BGM 파일명은 유지합니다. 새 BGM 이름은 기존곡으로 충당할 수 없을 때만 사용합니다. 검색 후보가 여럿이면 별도 작업 폴더에서 `_candidate01`로 구분하고 확정 납품 때 CSV 이름으로 맞추세요.

## 검색과 제작 방법

게임 이름보다 **재질 + 행동 + 길이/반복 여부**로 찾으면 편집하기 좋습니다. 예를 들어 두쫀쿠는 `chocolate crack soft pop impact`, 거미줄은 `elastic whip sticky snap`, 가속은 `arcade boost short synth whoosh`로 찾습니다. 영문 검색어를 CSV에서 그대로 복사하고, 결과가 없으면 단어를 줄이세요. 단발은 `short`, `single`, `dry`; 반복은 `loop`, `seamless`; 배경음은 `instrumental`, `no vocals`를 붙입니다.

1. 후보는 항목당 2~3개만 모으고 실제 사용 구간을 잘라 비교합니다. 단독으로 멋진 소리보다 연속 조작과 BGM 위에서 잘 들리는 소리를 선택합니다.
2. 공통 전자음/가속/반전은 짧은 신스 합성이 효율적입니다. 왁스 균열·초콜릿·나무·고무줄은 실제 재질 녹음 또는 재질 효과음을 섞는 방식이 어울립니다.
3. BGM 제작 시 CSV 브리프에 ‘보컬 없음, 짧은 도입, 자연스러운 반복, 효과음 공간 확보’를 같이 전달합니다. 특정 원곡을 복제하는 지시보다 리듬·악기·분위기로 주문합니다.
4. 효과음 재료는 [Freesound](https://freesound.org/)에서 검색할 수 있습니다. 파일별로 이용조건이 다르므로 선택한 항목의 라이선스와 제작자를 기록합니다. CC0·CC BY·비상업 조건 등이 구분되어 있습니다. [공식 FAQ](https://freesound.org/help/faq/)
5. 음악과 효과음 후보는 [Pixabay](https://pixabay.com/)에서도 검색할 수 있습니다. 선택한 파일의 상세 페이지와 사용 조건을 함께 남깁니다. 무료 표기만으로 모든 용도를 단정하지 않고 프로젝트에 넣을 수 있는지 확인합니다. [공식 이용조건 요약](https://pixabay.com/service/license-summary/)

밈의 원본 대사/음악은 현재 자료만으로 전부 확정할 수 없어 필수 목록에 넣지 않았습니다. 특히 E1/E4/E7/E10의 특정 원본 음성은 추측하지 않았습니다. 나중에 정확한 밈 레퍼런스가 정해지면 P2 연출에 추가하면 됩니다.

## 게임에서 확인할 것

- BGM을 켠 상태에서 조작·충돌·정답이 구별되는지 확인합니다. 중요한 순간만 BGM을 잠깐 낮추는 방식을 검토하세요.
- E4는 새 탭에서만 가속음이 나고, 손을 뗀 뒤 브레이크가 실제 미끄러짐과 함께 끝나야 합니다. 충돌음은 공통 시간 손실음을 재사용합니다.
- E8은 연결·해제·새 앵커 보상이 구별되어야 합니다. 원작 영화 소리 없이 고무줄/공기 효과로 컨셉을 전달하는 안입니다.
- E5는 표적 명중이 목재 파편보다 잘 들려야 합니다. E7은 감속할수록 딸깍 간격이 벌어져야 합니다.
- 반복음은 정지·실패·일시정지·스테이지 전환에서 꺼져야 합니다. 연속 충돌이나 파편으로 같은 소리가 겹쳐 과하게 커지지 않도록 묶어서 재생합니다.
