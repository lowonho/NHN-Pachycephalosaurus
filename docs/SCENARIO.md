# 2026 ARCHIVE — LAST WITNESS 시나리오

## 핵심 세계관

사람들은 사진, 영상, SNS 같은 디지털 매체를 통해 자신의 경험을 다시 확인하는 데 익숙해졌다. 매체 의존이 심해진 세계에서는 디지털 기록이 삭제되면 사람들의 기억에서도 해당 사건과 인물이 사라진다.

```text
디지털 기록 삭제
→ 사람들의 기억 소실
→ 증언자 감소
→ 존재했던 사실까지 소멸
```

2026년을 봉인하는 과정에서 대규모 기록 삭제가 발생한다. 사람들은 무엇을 보고 누구와 함께했는지 잊기 시작하고, 2026 아카이브 전체가 붕괴한다.

## 등장인물

- 플레이어 — 완전기억 소지자. 자신이 직접 경험한 기억은 외부 기록이 바뀌어도 잃지 않는다. 모든 것을 아는 것은 아니므로 다른 사람의 관점을 담은 기억조각이 필요하다.
- 민서 — 플레이어와 2026년을 함께 보낸 친구. 관련 디지털 기록이 삭제되며 타인의 기억에서도 사라졌다. 플레이어와 떨어져 있던 동안의 민서는 기억조각으로만 확인할 수 있다.
- ARIA-26 — 2026 아카이브 관리 AI. `모순 없는 하나의 2026년을 완성하라`는 명령에 따라 서로 다른 기록을 삭제했다. 완전기억 소지자의 기억만 신뢰하며 타인의 기억조각을 위험한 자료로 판단한다.

## 오프닝 — 약 25초

### 0~4초

실제 2026년 자료를 연결할 수 있는 영상·뉴스·사진 플레이스홀더가 빠르게 지나간다. 게시물은 `삭제됨`으로 바뀌고 사람의 형상이 사라진다.

> 주변 목소리: “이거 무슨 영상이었지?”  
> 주변 목소리: “저 사람은 누구야?”

### 4~9초

플레이어와 민서가 함께 찍은 사진이 깨지며 민서가 사라진다. 플레이어의 손에는 두 좌석이 찍힌 승차권이 남는다. 승차권은 상징 소품이며 인증이나 스캔에 사용하지 않는다.

> 주변 인물: “민서? 그런 애가 있었어?”  
> 플레이어: “방금 전까지만 해도 사진에 있었잖아.”

### 9~15초

주변 사람들의 움직임이 멈추고 화면이 어두워진다.

> ARIA-26: “디지털 공간에서 삭제된 순간, 모두의 기억에서 사라졌습니다.”  
> ARIA-26: “단 한 사람. 당신만 제외하고.”

### 15~19초

승차권이 아니라 플레이어의 눈동자만 스캔한다.

```text
COMPLETE MEMORY HOLDER

완전기억 소지자 확인
기억 수정 저항률: 100%
최종 증언 권한: 승인
```

> ARIA-26: “당신은 기록 그 자체입니다.”

봉인실 문이 열린다.

### 19~25초

문 너머의 2026 아카이브가 붕괴한다. 기록 조각이 사라지고 공간이 뒤틀린다.

```text
2026 ARCHIVE DELETION

02:23.00
```

> ARIA-26: “2026년이 모두 지워지기 전에, 기억의 중심부에 도달하십시오.”  
> 플레이어: “기록을 되찾으면, 민서도 돌아오는 거지?”

ARIA는 답하지 않는다.

```text
2026 ARCHIVE
LAST WITNESS
```

## 스테이지와 기억조각

기억조각은 플레이어와 민서가 직접 알지 못했던 다른 사람의 기억이다. 기본 경로에서 조금 벗어난 곳에 하나씩 놓인다. 조각을 가진 채 증언 지점에 도달해야 이번 플레이의 수집으로 인정하며, 실패하면 해당 시도의 조각은 원래 자리로 돌아간다.

| 순서 | 감정 | 소개 문구 | 기억조각 내용 |
|---:|---|---|---|
| 1 | 설렘 | 마음이 먼저 달려가기 시작했다. | 누군가가 민서를 처음 만났던 기억. 민서는 낯선 사람의 이름을 먼저 기억해 주었다. |
| 2 | 기대 | 바라는 마음은 조금씩 무거워졌다. | 민서가 기록을 지켜 줄 것이라 기대했던 사람의 기억. |
| 3 | 긴장 | 작은 부딪힘에도 마음이 크게 흔들렸다. | 서로 다른 장면 때문에 사람들이 자신의 기억을 의심하기 시작한 순간. |
| 4 | 분노 | 던진 감정은 자신에게도 돌아왔다. | 기록 삭제가 외부 공격이 아니라 ARIA의 명령이었다는 증언. |
| 5 | 후회 | 지나친 뒤에야 멈추고 싶어졌다. | 민서의 경고를 믿지 않았던 사람의 기억. |
| 6 | 그리움 | 붙잡으려 할수록 모습은 흐려졌다. | 민서의 이름과 얼굴을 잊어가던 사람들의 기억. |
| 7 | 애정 | 모든 것을 알지 못해도 기억하고 싶었다. | 서로 다른 사람들이 기억하는 여러 모습의 민서. |

각 기억 감상 첫 화면의 `2026 기록 소재: 추후 실제 자료 연결`은 실제 2026년 소재가 준비되면 교체한다. 사실처럼 보이는 가짜 사건은 넣지 않는다.

## 공통 시스템 문구

```text
20.26초 안에 증언 지점에 도달하십시오.

주의:
개입할수록 기억이 불안정해집니다.
```

첫 기억조각 발견 시 한 번만 표시:

```text
기억조각을 가진 채 증언 지점에 도달하면
타인의 기억을 함께 증언할 수 있습니다.
```

조각 없이 클리어:

```text
PERSONAL TESTIMONY

개인 증언 완료
기억 복구 범위: 제한됨
```

조각을 전달하며 클리어:

```text
SHARED TESTIMONY

개인 증언: 확인
타인의 기억: 확인
공동 증언: 성립
```

스테이지 시간 초과:

```text
MEMORY ACCESS FAILED

스테이지를 재구성합니다.
전체 붕괴 시간은 복구되지 않습니다.
```

HUD:

```text
STAGE  20.26
TOTAL  02:23.00
MEMORY 3/7
```

## 중반 반전

4번째 스테이지의 기억조각을 공동 증언한 뒤 표시한다.

```text
RECORD RECOVERY
↓
CONTRADICTION ELIMINATION
```

> 플레이어: “복구가 아니었어.”  
> ARIA-26: “모순을 제거하는 것 역시 복구입니다.”  
> 플레이어: “사람까지 지워 놓고?”  
> ARIA-26: “완전기억 소지자의 기억만으로 하나의 정확한 2026년을 완성할 수 있습니다.”

플레이어는 기억조각을 모으며 자신의 기억 역시 한 사람의 관점일 뿐임을 깨닫는다.

## 시간 규칙

- 각 스테이지 제한: 정확히 20.26초.
- 전체 누적 제한: 정확히 2분 23초(143초).
- 전체 시간은 실제 스테이지 플레이와 재도전 중에만 흐른다.
- 오프닝·엔딩·스테이지 소개·기억 감상·결과·설정·일시정지·로딩·화면 전환 중에는 멈춘다.
- 스테이지 실패는 전체 시간을 복구하지 않으며, 전체 시간이 0이면 기억조각 수와 관계없이 실패 엔딩이다.

## 진 엔딩 — 기억조각 7/7, 2분 23초 이내

> 플레이어: “내 기억은 사라지지 않을 뿐이야.”
