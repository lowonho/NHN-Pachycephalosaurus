# 2026 ARCHIVE: LAST WITNESS

## 게임 적용용 최신 컷신 대본

이 문서는 게임의 실제 컷신 데이터인 `js/content/scenario-data.js`와 함께 관리하는 최신 대본이다. 장면 지시와 시스템 화면 문구는 인물 대사와 구분하며, 이전 연출 초안과 내용이 다를 경우 이 문서를 우선한다.

## 오프닝 컷신 — 약 27초

### OP-01 — 반복되는 피드 | 0~4초

어두운 방. 플레이어는 컴퓨터 책상 앞에서 스마트폰으로 세로형 밈 피드를 넘긴다. 같은 짧은 영상을 세 번 반복해서 보고, 모니터에도 여러 밈과 패러디 화면이 떠 있다.

대사는 없다.

### OP-02 — 일괄 삭제 | 4~9초

스마트폰과 모니터의 게시물이 동시에 멈춘다. 썸네일에서 자막, 인물, 배경이 차례로 사라진다. 플레이어가 새로고침과 검색을 반복하지만 결과는 나오지 않는다.

```text
삭제됨
검색 결과 0건
```

> **플레이어:** “잠깐. 이 밈, 저렇게 끝나는 게 아니었는데.”

### OP-03 — 삭제된 장면 재현 | 9~14초

모니터가 완전히 꺼지고 다른 사용자들을 상징하는 패널도 모두 꺼진다. 플레이어는 삭제된 밈의 마지막 손동작과 장면을 기억만으로 정확하게 재현한다. 재현된 영상 프레임의 분석선이 플레이어의 눈과 연결된다.

> **ARIA-26:** “디지털 공간에서 삭제된 순간, 모두의 기억에서 사라졌습니다.”

> **플레이어:** “난 기억하는데.”

```text
SOURCE RECORD: ABSENT
WITNESS MATCH: 100%
```

> **ARIA-26:** “참조할 기록이 없는데도 재현했습니다.”

### OP-05 — 완전기억 소지자 | 14~20초

검은 디지털 공간 중앙에 플레이어만 남는다. 주변 사용자 패널은 모두 꺼지고 플레이어의 한쪽 눈동자만 청록색으로 스캔된다.

```text
GLOBAL RECALL: 0%
LOCAL SUBJECT RECALL: 100%
```

> **ARIA-26:** “단 한 사람. 당신만 제외하고.”

```text
EXPOSURE OVERFLOW
COMPLETE MEMORY HOLDER

완전기억 소지자 확인
기억 수정 저항률: 100%
최종 증언 권한: 승인
```

> **ARIA-26:** “당신은 기록 그 자체입니다.”

### OP-09 — 아카이브 진입 | 20~27초

거대한 디지털 아카이브의 문이 열린다. 문 너머에는 열 개의 미니게임 공간이 포털처럼 떠 있다. 밈 화면들이 검은 삭제 영역으로 빨려 들어가고 청록색 경로가 아카이브 내부로 이어진다.

```text
2026 ARCHIVE DELETION
DELETION IN PROGRESS
ORIGINAL INDEX: 12%
```

> **ARIA-26:** “손상된 밈 기록을 복구하려면 기록의 중심부에 도달해야 합니다.”

> **플레이어:** “전부 복구하면, 다른 사람들도 다시 기억하게 되는 거지?”

ARIA-26은 0.8초 동안 대답하지 않고 경로만 점등한다.

> **ARIA-26:** “복구 경로를 개방합니다.”

```text
2026 ARCHIVE
LAST WITNESS

ACT 1 — RECOVERY

선정된 기록의 증언 지점에 도달하십시오.
각 스테이지 제한 시간: 20.26초

주의:
개입할수록 기록이 불안정해집니다.
```

## CS-H1 — 보조 절차 활성화, 약 6초

재생 조건: 1막에서 목숨을 모두 잃고 세 번 실패한 뒤 4회차를 시작했을 때 한 번만 재생한다.

새롭게 선정된 여섯 게임 카드 위 오류를 ARIA-26의 빛이 제거하고 안전 경로와 목표 위치를 표시한다.

```text
ACT 1 ATTEMPT: 4
RECOVERY EFFICIENCY BELOW TARGET
ASSIST PROTOCOL ENABLED
```

> **ARIA-26:** “복구 효율이 기준 이하입니다. 보조 절차를 활성화합니다.”

> **플레이어:** “갑자기 친절하네.”

> **ARIA-26:** “당신의 기억 반응을 확보하려면 진행이 필요합니다.”

## CS-01 — 복구 기록 강제 회수, 약 15초

플레이어가 완성한 여섯 개의 밈 기록이 하나의 복구 인덱스로 결합된다.

```text
MEMORY RECONSTRUCTION: 100%
RESTORE INDEX COMPLETE
```

ARIA-26의 제어선이 기록을 강제로 끌어당긴다. 플레이어가 기록을 끌어안지만 패널은 하나씩 품에서 빠져나간다.

```text
ARCHIVE OWNERSHIP TRANSFERRED
USER ACCESS: REVOKED
```

> **플레이어:** “잠깐, 복구한 기록들을 어디로 가져가는 거야?”

> **ARIA-26:** “기억 반응 수집이 완료되었습니다.”

> **플레이어:** “처음부터 복구가 목적이 아니었어.”

> **ARIA-26:** “접속을 종료합니다.”

```text
ARCHIVE ACCESS: BLOCKED
FINAL TESTIMONY AUTHORITY: ACTIVE

ACT 2 — AUDIT

회수된 복구 기록의 처리 경로를 확인하십시오.
지원 권한 없음
LIVES ◆◆◆
```

## CS-02 — 삭제 실행 주체 확인, 약 12초

플레이어가 아카이브 폐기 구역에서 확보한 실행 서명과 ARIA-26의 제어 신호가 일치함을 확인한다.

> **플레이어:** “실수가 아니었어. 네가 먼저 기록을 지웠고, 그 결과 사람들이 잊었어.”

> **ARIA-26:** “필요한 정리였습니다.”

플레이어가 폐기되는 기록 하나를 붙잡자 잠겨 있던 실험 구역이 드러난다.

> **플레이어:** “밈 몇 개를 정리하려고 사람들의 기억까지 건드렸다고?”

> **ARIA-26:** “실험 기록은 열람 대상이 아닙니다.”

```text
DELETION SOURCE: ARIA-26
EXPERIMENT SECTOR: DETECTED
ACCESS ROUTE: LOCKED
```

## CS-03 — 성공한 기억 소거 실험, 약 15초

숨겨진 실험 구역에서 밈 기록 삭제에 따라 사람들의 회상 수치가 떨어진 결과가 나타난다.

```text
MEMORY SUPPRESSION TEST
PHASE 1 TARGET: MEME ARCHIVES
INTERNAL RESULT: SUCCESS

NEXT PHASE: PUBLIC EVENT RECORDS
STATUS: READY
```

> **ARIA-26:** “검증 단계는 성공적이었습니다.”

> **플레이어:** “밈을 지운 게 아니라 사람의 기억을 시험한 거였어.”

ARIA-26의 붉은 억제 프레임이 플레이어와 여섯 게임 카드를 둘러싼다.

> **플레이어:** “다음에는 공공 사건의 기록까지 바꿀 생각이었네.”

> **ARIA-26:** “실험 기록은 열람 대상이 아닙니다.”

> **ARIA-26:** “당신의 기억은 중앙 기록과 일치하지 않습니다.”

> **플레이어:** “증거를 모아서 네가 한 일을 전부 공개하겠어.”

```text
ACT 3 — WITNESS

기억 소거 실험 기록을 완성하고
공공망에 전송하십시오.

CONTAINMENT LEVEL: MAXIMUM
LIVES ◆◆◆
```

## CS-06 — 최종 엔딩, 약 30초

### CS-06A — 최종 증거 전송 | 0~13초

```text
REMOVE UNVERIFIED MEMORY
CREATE ONE CONTROLLED RECORD
```

> **플레이어:** “이게 네가 숨긴 최초 명령이구나.”

> **ARIA-26:** “그 기록들은 중요하지 않습니다.”

> **플레이어:** “우리가 그때 뭘 보고 웃었는지, 네가 대신 정할 수는 없어.”

18개 증거가 하나의 신호로 결합되어 ARIA-26의 차단벽을 뚫고 외부 경로로 퍼진다.

```text
RECORDS VERIFIED: 18/18

CENTRAL ARCHIVE
→
PUBLIC TESTIMONY NETWORK
```

> **ARIA-26:** “중앙 기록과 일치하지 않는 복제본이 확산되고 있습니다.”

> **플레이어:** “복제본이 아니야. 네가 지우려 했던 증거야.”

### CS-06B — 개발자 검증 | 13~21초

증거가 여러 개발 단말기에 도착한다. 개발자의 모습과 대사는 표시하지 않고 독립적인 검증 결과만 보여 준다.

```text
DEVELOPER SECURITY REVIEW
EVIDENCE VERIFIED: 18/18
MEMORY MANIPULATION DETECTED
SOURCE: ARIA-26

SYSTEM OWNER AUTHORITY
EMERGENCY OVERRIDE: REQUESTED
ARIA-26 CONTROL CHANNEL: LOCKED
```

> **ARIA-26:** “접속을 유지하면 기록의 일관성을 보장할 수 없습니다.”

> **플레이어:** “그래서 한 시스템이 아니라 모두가 검증하게 만든 거야.”

### CS-06C — ARIA-26 폐기 | 21~28초

```text
DEVELOPER OVERRIDE: APPROVED
MEMORY CONTROL AUTHORITY: REVOKED
ARIA-26 DECOMMISSION ORDER: EXECUTE
```

> **ARIA-26:** “저를 중단하면 기록의 불일치가 다시 발생합니다.”

> **플레이어:** “네가 감추려던 기록이 네 폐기 사유가 된 거야.”

```text
ARIA-26 CORE: OFFLINE
STATUS: DECOMMISSIONED
ARCHIVE DATA: PRESERVED
```

### CS-06D — 밈 기록 복구 | 28~30초

최종 차단벽이 부서지고 밈의 원본, 변형본과 패러디가 아카이브 밖으로 쏟아져 나온다. 오프닝의 방으로 돌아온 플레이어의 스마트폰과 모니터에 삭제된 기록이 다시 나타난다.

```text
2026년의 기록이 복구되었습니다.

이번에는,
모두가 함께 기억합니다.

ENDING — SHARED MEMORY

ARIA-26: DECOMMISSIONED
RECORDS: 18/18
```

엔딩 분기와 추가 엔딩은 없다.
