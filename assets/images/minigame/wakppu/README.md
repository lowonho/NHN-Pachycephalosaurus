# 왁뿌볼 스테이지 에셋 2K

첨부 플레이 컨셉 이미지를 스타일·구도 기준으로, 말랑이 실사 이미지를 내부 왁스/반죽 질감 기준으로 사용해 제작했습니다.

- 왁뿌볼 1~3: 서로 다른 표정
- 왁뿌볼 4: 표정 없음, 내부 재료 완전 혼합
- 모든 왁뿌볼: 투명 고무막과 상단 매듭 유지, 내용물 외부 유출 없음
- 버터말랑이: 장·중·단 3종
- 왁뿌바: 연결된 반파 1종, 정확히 두 조각으로 분리된 완파 1종
- 파란 호빵 말랑이: 중간·짧은 길이 2종
- 배경: UI·캐릭터·발판 없는 키덜트 컬렉터 룸 1종

에셋은 PNG이며 긴 변 2,048px 기준으로 정리했습니다. 배경은 2,048×1,152px, 왁뿌볼은 2,048×2,048px입니다. 단독 오브젝트는 포토샵 누끼 작업이 쉬운 중립 회색 배경으로 제작했습니다.

생성 방식: built-in image generation, 개별 프롬프트 12회.
