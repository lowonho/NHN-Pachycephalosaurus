# E7 월드컵 조추첨

- 멕시코·남아공·체코·일본·프랑스·브라질·독일·이탈리아의 국기와 이름을 같은 크기의 여덟 칸에 표시합니다. 목표는 한국 상대 세 국가 중 하나입니다.
- 오른쪽 고정 화살표 아래 목표 국가가 멈추면 성공합니다. 감독의 몸과 실패 뒷모습은 원판 밖에 배치하고 국기는 원판 안쪽에 둡니다.
- 원판을 슥 드래그한 뒤 놓으면 드래그 방향으로 회전합니다. 직선 이동 거리 / 100 / 드래그 시간으로 초기 각속도를 계산하고, 멈춰 잡고 있으면 힘이 줄어듭니다. 드래그 중에는 원판 각도를 변경하지 않아 정답 위치에 끌어 놓을 수 없습니다.
- 최소 드래그 이동은 12px, 최소 속도는 2.4rad/s, 최대 속도는 10rad/s입니다. 속도 게이지로 발사 가능한 입력인지 표시합니다. 짧거나 너무 느린 입력은 판정하지 않습니다.
- 실패마다 마찰은 4rad/s²에서 78%씩 줄며 최소 1.5rad/s²입니다. 칸 수·국가 배치는 유지합니다. 같은 힘이면 더 멀리 돌아갑니다.
- 원본 coach-sheet.png의 400×793 프레임 중 앞의 네 장만 사용합니다. 실패 시 coach-back.png의 인물 영역을 1.1초 표시합니다.
- tests/e7-draw-check.js에서 결정적인 회전량, 마찰 감소, 고정 칸, 실패 연출, 성공 및 재시작을 검사합니다.
- 세로·대각선·가로 직선 입력과 중심에서 시작하는 입력을 지원합니다. 세로 성분이 충분하면 아래쪽은 시계 방향, 위쪽은 반시계 방향입니다. 가로 위주의 입력은 왼쪽이 시계 방향입니다.
- tuning.countryCount=8로 칸 수를 관리합니다. 현재 목록보다 늘릴 때에는 국가 목록과 flag 렌더러에도 추가합니다.
- 뒷모습은 150×300으로 표시하고 발 위치를 y=496에 맞춰 원본 여백을 제외한 인물 높이를 정면과 맞췄습니다.
