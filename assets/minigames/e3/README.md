# e3 사람 쌓기 에셋 가이드

현재는 코드로 그린 흰색 무표정 마네킹을 사용합니다. 그림과 충돌체는 `js/archive/stages/e3_humanStack.js`의 `poses`에 있는 같은 팔/다리 좌표를 사용합니다. 메챠 카멜레온의 흰색 사람·포즈라는 시각 방향을 참고했으며, 원작 모델이나 텍스처를 복사한 에셋은 아닙니다. 참고: [공식 Steam 소개](https://store.steampowered.com/app/4704690/MECCHA_CHAMELEON/).

## 이미지 적용

투명 배경 PNG/WebP/SVG를 이 폴더에 놓고 `../manifest.js`의 e3 경로를 채웁니다.

```js
e3: {
  person: null,
  person_crouch: 'assets/minigames/e3/person-crouch.webp',
  person_wide: 'assets/minigames/e3/person-wide.webp',
  person_reach: 'assets/minigames/e3/person-reach.webp',
},
```

| 키 | 자세 | 기준 캔버스 | 머리 중심 | 발바닥 y |
| --- | --- | --- | --- | --- |
| person_crouch | 무릎을 굽히고 팔을 벌려 버티기 | 94×88 | (0, -28) | +39 |
| person_wide | 팔을 넓게 벌리고 서기 | 112×96 | (0, -30) | +45.8 |
| person_reach | 양팔을 올린 만세 | 88×116 | (0, -30) | +46.8 |

- 좌표 (0, 0)은 **이미지 캔버스의 정중앙**입니다. 머리 중심과 발바닥은 그 중심으로부터의 상대 좌표이며, y는 아래가 양수입니다.
- 같은 비율의 4배 이미지(376×352, 448×384, 352×464)도 사용할 수 있습니다. 가운데 원점과 포즈를 유지하세요.
- 자동 여백 자르기나 자세별 임의 크기 변경은 하지 마세요. Matter가 계산한 질량중심과 이미지 중심의 차이는 렌더러가 자동 보정합니다.
- 자세별 경로가 없으면 `person` 공통 이미지를 사용하고, 그것도 없으면 코드 마네킹을 표시합니다. 실제 포즈와 충돌을 맞추려면 세 자세를 각각 제공하세요.
- 팔/다리 위치를 바꾸는 아트라면 `poses.limbs`와 `poses.head`도 함께 수정합니다. `tuning.debugPhysics = true`로 실제 충돌선과 무게중심을 표시할 수 있습니다.
- 이미지만 교체했다면 새로고침하면 됩니다. JS도 바꿨다면 `scripts/build-archive-classic.ps1`로 번들을 다시 빌드합니다.

## 물리 모델

각 사람은 머리 1개와 몸통·팔·다리 캡슐 11개를 합친 **자세가 고정된 강체**입니다. 몸 전체의 질량, 관성, 회전, 마찰, 반발을 Matter로 계산합니다. 관절이 풀어지는 래그돌 방식은 아닙니다.

사람을 내려놓은 위치와 접촉점에 따라 미끄러지거나 기울어지고, 넘어진 사람은 계속 움직이는 잔해로 남습니다. 성공 판정은 바닥/받침대부터 실제 접촉이 이어지고 충분히 안정된 사람만 포함합니다. 공중의 낙하물과 흔들리는 탑은 목표 높이를 넘었더라도 바로 성공하지 않습니다.
