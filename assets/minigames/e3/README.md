# e3 사람 쌓기 에셋 가이드

떨어지는 사람은 `assets/images/minigame/stacks/metcha/pose1.png` ~ `pose8.png` 여덟 장이고, 성공선 오른쪽에 세워 두는 표지는 같은 폴더의 `line.png`입니다. 메챠 카멜레온의 흰색 사람·포즈라는 시각 방향을 참고했으며, 원작 모델이나 텍스처를 복사한 에셋은 아닙니다. 참고: [공식 Steam 소개](https://store.steampowered.com/app/4704690/MECCHA_CHAMELEON/).

| 파일 | 자세 | HUD 이름 |
| --- | --- | --- |
| pose1 | 옆으로 누워 팔을 접은 자세 | 옆으로 눕기 |
| pose2 | 두 손으로 머리를 감싼 자세 | 머리 감싸기 |
| pose3 | 팔다리를 활짝 편 자세 | 큰대자 |
| pose4 | 몸을 말아 웅크린 자세 | 웅크리기 |
| pose5 | 허리를 굽혀 숙인 자세 | 숙이기 |
| pose6 | 두 팔을 굽혀 든 자세 | 알통 자랑 |
| pose7 | 차렷 자세 | 차렷 |
| pose8 | 다리를 모으고 앉은 자세 | 앉기 |
| line | 왼쪽 화살표를 단 차렷 자세 | (성공선 표지) |

## 그림을 바꾸면 하는 일

원본 PNG를 덮어쓰고 굽기 스크립트를 한 번 돌리면 끝입니다. 표시 크기도 충돌체도 그림에서 다시 뽑습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/bake-stack-poses.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-archive-classic.ps1
```

굽기 스크립트가 만드는 것은 두 가지입니다.

- `assets/images/minigame/stacks/metcha/*.webp` — 게임이 실제로 읽는 그림. 투명 여백을 자르고, 반투명 가장자리의 색을 옆 픽셀 색으로 덮은 뒤(원본은 투명 픽셀 밑에 하늘색이 깔려 있어 그냥 구우면 파란 테두리가 남습니다) 표시 크기의 두 배로 줄여 `-q 90 -alpha_q 100`으로 굽습니다. 장당 2.5~4.8KB로, 원본 PNG의 1% 남짓입니다.
- `assets/minigames/e3/pose-shapes.js` — 표시 크기와 사각형 충돌 조각. `index.html`이 `manifest.js` 바로 뒤에서 읽습니다.

`cwebp`(libwebp)가 PATH에 없으면 `-Cwebp` 로 경로를 넘기세요. 배포판은 <https://storage.googleapis.com/downloads.webmproject.org/releases/webp/> 에 있습니다.

## 원본 그림 규칙

- **투명 배경 PNG**로 만듭니다. 여백은 스크립트가 알아서 자르므로 얼마가 남아 있어도 상관없습니다.
- 여덟 장은 **같은 배율로 렌더한 같은 사람**이어야 합니다. 스크립트는 여덟 장 중 가장 긴 세로(=똑바로 선 사람)만 게임 좌표 116px에 맞추고 나머지에 같은 배율을 적용하므로, 자세마다 확대·축소해 두면 누운 사람이 선 사람만 해집니다.
- 자세는 **정방향으로 하나만** 그립니다. 옆으로 눕히거나 뒤집은 그림을 따로 만들 필요는 없습니다. `tuning.dropAngles`가 낙하마다 몸 전체를 돌려 줍니다.
- 원점은 잘라낸 그림의 **정중앙**입니다. Matter가 계산한 질량중심과의 차이는 렌더러가 자동으로 보정합니다.

## 충돌체

사람 하나는 **자세가 고정된 강체**이고, 그 속은 그림의 알파에서 뽑은 사각형 열~스무 개입니다. 스크립트는 그림을 게임 좌표 4.2px짜리 격자로 나눠 알파가 절반 넘게 찬 칸만 "몸"으로 보고, 빈 칸이 하나도 없는 가장 넓은 직사각형을 스무 개까지 차례로 떼어 냅니다. 그래서

- 투명한 여백은 어떤 조각도 덮지 않습니다 — 큰대자의 팔 사이나 다리 사이로 다른 사람이 지나갑니다.
- 몸이 있는 자리는 89~100% 덮입니다. 남는 곳은 격자보다 얇은 팔다리 끝뿐입니다.

관절이 풀어지는 래그돌이 아니라 몸 전체의 질량·관성·회전·마찰을 Matter로 계산합니다. 넘어진 사람은 계속 움직이는 잔해로 남습니다. 성공 판정은 바닥/받침대부터 실제 접촉이 이어진 탑이 목표 높이 216을 3초 연속 유지하는 것이고, 목표 아래로 내려가거나 지지를 잃으면 0초로 돌아갑니다. 공중의 낙하물은 높이에 포함하지 않습니다.

옛 마네킹보다 홀쭉해서 한 명이 자리를 잡는 데 1초쯤 걸립니다. 그보다 빨리 떨어뜨리면 이미 서 있는 사람을 무너뜨리기만 하므로, 검증 스크립트의 가상 플레이어도 1초 간격으로 떨어뜨립니다.

`tuning.debugPhysics = true`로 실제 충돌 사각형과 무게중심을 화면에 표시할 수 있습니다.
