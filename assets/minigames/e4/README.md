# E4 조선 마을 렌더링 (부분 적용)

## 적용과 제한
- 맵 연결 데이터와 route RNG, 키보드 입력, 입력당 가속, 반지름 10 충돌체, 20.26초, 클리어 조건은 그대로입니다.
- 사용자 요청으로 벽 두께를 12px에서 28px로 늘렸습니다. 기와집 그림은 최대 11px에서 27px로 약 2.45배 커졌습니다. 전체 맵을 한 화면에 유지하기 위해 통로는 84×112에서 66×90으로 조정했습니다. 캐릭터 충돌 지름은 20px 그대로이며, 맵 연결과 생성 알고리즘은 유지합니다.
- buildings의 role/cellsW/cellsH로 1×1과 향후 1×2를 정의합니다. 같은 기존 벽 내부에 모두 들어갈 때만 배치합니다. 매 프레임 종류를 바꾸거나 게임 난수를 소비하지 않습니다.
- 플레이어 교체 어댑터는 통로 짧은 변의 70%로 그림을 맞추고 좌우 반전만 합니다. 충돌 크기는 그대로입니다. 현재 검증된 투명 캐릭터가 없어 기본 표시를 유지합니다.

## 이미지
- originals/player.png, originals/thatch.png, originals/tile-roof.png는 다운로드 원본 복사본입니다.
- tile-roof.png: 이미지 도구로 분리한 투명 기와집. 1312×1199, alpha=0 픽셀 703054개. 실제 그림 경계 [151,43,1008,1021]을 Phaser 프레임으로 사용합니다.
- 캐릭터·초가집은 두 번의 처리 모두 alpha=0 픽셀이 0개였고 체크무늬가 남아 제외했습니다. 흰 머리띠를 지우는 색상 일괄 삭제는 사용하지 않았습니다.
- 필요한 에셋: 실제 알파가 있는 엄흥도 단일 프레임과 초가집 PNG. 이후 manifest의 e4.player/e4.thatch 경로 및 E4_VILLAGE_BOUNDS에 실제 그림 경계를 등록하면 됩니다.
- 상하 전용 프레임은 추가하지 않았습니다. 추후 방향별 애니메이션은 E4_VILLAGE.actor/player 교체 지점에서 확장합니다.

## 실행 검증
- powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-archive-classic.ps1
- powershell -NoProfile -ExecutionPolicy Bypass -File tests/minigame-browser.ps1 -E4Only
- 기존 충돌/가속/제동/최고속도 관통 방지/시간/재시작 및 랜덤 미로 25개 실제 이동 클리어 통과.
- tests/e4-village-check.js: 건물 경계·비율·고정 종류, 원본 물리 상수, 전체 카메라 범위 통과.
- tests/.artifacts/e4-maze.png에서 화면 확인. 기와집에 체크무늬와 늘어남 없음. 전체 맵은 필드 중앙에 정렬되어 위아래 여백이 같고, HUD 아래에 배치됩니다.
## 속도와 제동 조정
- 최고속도 1100 → 800px/s, 제동 감속 7200 → 2400px/s². 최고속도에서 키를 놓으면 장애물이 없을 때 약 0.33초 동안 133px 미끄러집니다. 기존 최고속도에서는 약 0.15초/84px였습니다.
- 벽에 부딪히면 해당 방향의 속도를 즉시 멈추며 기존 시간 차감 규칙을 유지합니다. 랜덤 미로 25개 실제 이동 클리어와 제동 거리/시간 간격 독립성 검사를 통과했습니다.
