# e8 거미줄 질주 에셋

실행 파일은 `js/archive/stages/e8_webSwing.js`입니다. 시소를 대체한 자동 전진 게임이며 코인은 없습니다.

기본 캐릭터는 빨강/파랑 슈트, 흰 눈의 마스크와 거미 문양을 Canvas로 그립니다. `hero()`에서 달리기와 공중 자세를 조정할 수 있습니다. 엠파이어 스테이트 빌딩은 `tower()`에서 계단식 크라운과 첨탑을 그리며 첨탑 끝이 거미줄 연결점입니다. 배경 빌딩에는 충돌하지 않고 앞쪽 옥상에만 착지합니다.

캐릭터 이미지를 적용하려면 투명 배경 파일을 이 폴더에 넣고 `assets/minigames/manifest.js`에 등록하세요.

```js
e8: { player: 'assets/minigames/e8/player.webp' }
```

- 표시 크기: 40×48 월드 픽셀. 속도가 빨라지면 카메라 배율에 따라 작아집니다.
- 회전 중심: 이미지 중심을 골반보다 약간 위에 둡니다. 투명 여백은 최소화하세요.
- 물리 중심은 `(state.x, state.y)`, 착지 판정은 중심 아래 18px입니다. 그림 교체로 판정은 바뀌지 않습니다.
- 기본 그림의 자세 애니메이션은 이미지 교체 후 적용되지 않으며 전체 회전은 유지됩니다.
- 배경, 옥상, 첨탑, 거미줄은 코드 도형입니다. 건물 외형을 바꾸더라도 첨탑 좌표와 줄 시작점은 일치시켜 주세요.

속도와 간격은 파일 위쪽 `tuning`에서 조정합니다. 이미지를 적용한 뒤 원본 번들을 `scripts/build-archive-classic.ps1`로 갱신하세요.
