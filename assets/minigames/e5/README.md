# e5 두쫀쿠 새총

- 발사체: 두쫀쿠. 현재 초콜릿 겉면과 녹색 속을 코드로 그립니다.
- 파괴 대상: 2층 나무집 두 채 안의 두딱쿠 4개. 각 집의 기둥 4개·층판 2개·지붕 1개는 독립된 Matter 강체입니다.
- 기둥을 밀면 층판과 지붕이 무너지며, 자재와 두딱쿠 사이의 상대 충돌 속도로 압사 피해를 계산합니다. 가만히 받치고 있는 자재는 피해를 주지 않습니다.
- 목재를 전부 없앨 필요는 없습니다. 두딱쿠 4개만 처치하면 성공하며 목재 잔해는 물리 월드에 남습니다.
- 이미지 교체: assets/minigames/manifest.js의 e5.projectile / e5.target에 투명 이미지 경로를 지정합니다.
- 권장 비율: projectile은 1:1, target은 6:5. 물리 판정은 이미지와 독립입니다.
- 난이도는 js/archive/stages/e5_slingshot.js의 tuning에서 조절합니다.
- targetHP는 내구도입니다. piercePower/pierceSpeed를 모두 넘는 발사만 관통합니다. 약한 충돌 피해는 최대 28이며 곧바로 지우지 않습니다.
- toppleAngle 이상의 기울기 또는 원래 위치에서 충분한 이동·낙하를 toppleHold초 유지하면 붕괴로 집계합니다. 잔해는 그대로 물리 월드에 남습니다.
- 20.26초 안에 4개를 무너뜨리면 성공합니다. 장력은 발사마다 5%p 감소해 100 → 95 → 90 → 85 → 80 → 76%로 내려갑니다.
- force=8.8, 최소 장력=76%는 후반 완전히 당긴 포물선이 마지막 집 지붕까지 닿도록 정한 값입니다. 낮은 직선 발사는 앞에 떨어지며 높은 각도로 위에서 내려치는 공략이 필요합니다.
- 실제 Matter 물리에서 최소 장력의 낮은 탄이 마지막 집에 못 닿고, 약 45도 탄은 하강하면서 지붕에 맞는 것을 tests/e5-slingshot-check.js로 검증합니다.

tests/e5-slingshot-check.js는 준비된 게임 브라우저에서 실행하는 전용 검증입니다.
건물 초기 안정성, 약한 탄의 기둥 이동, 윗층 붕괴와 거주자 피해, 강한 탄의 관통, 잔해, 당김 제한, 취소, 정지와 월드 정리를 검사합니다.

조준 보조는 처음 0.3초의 짧고 희미한 점선만 보여주며, 예상 충돌 위치는 표시하지 않습니다.
