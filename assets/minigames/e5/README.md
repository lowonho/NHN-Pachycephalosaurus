# e5 두쫀쿠 새총

- 발사체: 두쫀쿠. 현재 초콜릿 겉면과 녹색 속을 코드로 그립니다.
- 파괴 대상: 2층 과자집 두 채 안의 두딱쿠 4개. 각 집의 기둥 4개·층판 2개·지붕 1개는 독립된 Matter 강체입니다.
- 기둥을 밀면 층판과 지붕이 무너지며, 자재와 두딱쿠 사이의 상대 충돌 속도로 압사 피해를 계산합니다. 가만히 받치고 있는 자재는 피해를 주지 않습니다.
- 목재를 전부 없앨 필요는 없습니다. 두딱쿠 4개만 처치하면 성공하며 목재 잔해는 물리 월드에 남습니다.
- 이미지 교체: assets/minigames/manifest.js의 e5 항목에 역할별 투명 이미지 경로를 지정합니다. 물리 판정은 이미지와 독립입니다.
  - 두쫀쿠(발사체)는 상태별 네 장입니다. proud(대기) / tense(당기는 중) / launch(날아가는 중) / split(맞은 뒤).
  - 두딱깡은 target(성한 것) / targetHit(한 번이라도 맞은 것) 두 장입니다.
  - 과자집은 pillarLong(1층 기둥) / pillarMedium(2층 기둥) / floorSmall(가운데 층) / floorWide(지붕 밑 층) / roof(지붕),
    그리고 부러진 조각에 쓰는 pillarShort 입니다.
  - 배경과 소품은 backdrop(16:9 한 장) / table(조리대 상판) / brick(집 받침) / brickStar(장식) / slingshot(고무줄 없는 새총 몸통)입니다.
- 표시 크기는 e5_slingshot.js의 art 표가 정합니다. 판정 사각형보다 조금 크게 그려 웨이퍼 무늬가 눌리지 않게 하고,
  지붕만 그림 아랫변을 처마에 맞춥니다(위에 얹은 크림과 딸기까지 한 장이라 가운데를 맞추면 처마가 내려앉아 보입니다).
- 그림이 하나도 없으면 예전 진저브레드 도형으로 그대로 그립니다.
- 원본 png에서 webp를 굽는 일은 scripts/bake-ddujjonku.ps1이 합니다. 원본을 바꿨다면 다시 굽고 번들을 다시 빌드하세요.
- 난이도는 js/archive/stages/e5_slingshot.js의 tuning에서 조절합니다.
- targetHP는 내구도입니다. piercePower/pierceSpeed를 모두 넘는 발사만 관통합니다. 약한 충돌 피해는 최대 28이며 곧바로 지우지 않습니다.
- toppleAngle 이상의 기울기 또는 원래 위치에서 충분한 이동·낙하를 toppleHold초 유지하면 붕괴로 집계합니다. 파괴된 두딱쿠는 화면과 물리 월드에서 사라지고, 목재 잔해만 남습니다.
- 20.26초 안에 4개를 무너뜨리면 성공합니다. 장력은 발사마다 5%p 감소해 100 → 95 → 90 → 85 → 80 → 76%로 내려갑니다.
- force=8.8, 최소 장력=76%는 후반 완전히 당긴 포물선이 마지막 집 지붕까지 닿도록 정한 값입니다. 낮은 직선 발사는 앞에 떨어지며 높은 각도로 위에서 내려치는 공략이 필요합니다.
- 실제 Matter 물리에서 최소 장력의 낮은 탄이 마지막 집에 못 닿고, 약 45도 탄은 하강하면서 지붕에 맞는 것을 tests/e5-slingshot-check.js로 검증합니다.

tests/e5-slingshot-check.js는 준비된 게임 브라우저에서 실행하는 전용 검증입니다.
건물 초기 안정성, 약한 탄의 기둥 이동, 윗층 붕괴와 거주자 피해, 강한 탄의 관통, 잔해, 당김 제한, 취소, 정지와 월드 정리를 검사합니다.

조준 보조는 처음 0.3초의 짧고 희미한 점선만 보여주며, 예상 충돌 위치는 표시하지 않습니다.

## 구조물 강도

- 목재 내구도 woodHP=60, 1회 직격 피해 상한 woodHitMax=40. 충돌 속도 220px/s 이상이면 최소 30 피해로 같은 부위를 두 번 맞혀 파손시킬 수 있습니다. 약하게 스치는 탄은 더 필요합니다.
- 목재 연결부는 jointStiffness=.2로 건물을 지지합니다. 아래층 기둥이 파손되면 해당 집 전체의 연결부를 풀어 중력과 충돌에 의해 윗층과 지붕까지 넘어지게 합니다. 다른 집의 연결부는 유지합니다.
- 피해가 누적되면 균열과 내구도 바를 표시합니다. 약해진 자재를 마저 파손시키는 강한 탄은 관통할 수 있습니다.
- 조준선은 0.3초 길이를 유지하면서 점 반지름 3px, 시작 불투명도 90%로 선명도를 올렸습니다.

## 움직임과 다음 발사

- 맞은 목재의 연결부 강성은 남은 내구도에 비례해 약해집니다. 감쇠와 물리 수면으로 미세한 떨림이 무한히 이어지지 않도록 합니다.
- 발사 즉시 다음 조준을 막고, 게임 시간 1.5초가 지나면 공과 건물이 움직이는 중에도 다시 발사할 수 있습니다.
- 재장전 시간은 tuning.cooldown=1.5로 조절합니다. 일시정지 중에는 재장전 시간도 흐르지 않습니다.
- 다음 두쫀쿠의 표시와 남은 재장전 시간으로 발사 가능 여부를 보여 줍니다. 20.26초 제한시간은 기존대로 진행됩니다.

- 부러진 목재는 폭 70%, 높이 28%의 작은 잔해가 되어 기존 높이로 층판을 받치지 않습니다. 내구도가 절반 이하인 아래 기둥이 0.22rad 이상 꺾이면 완전히 파손되어 집 전체 연결을 해제합니다. 따라서 아래쪽을 강하게 잘 맞히면 한 발로도 붕괴할 수 있습니다.
