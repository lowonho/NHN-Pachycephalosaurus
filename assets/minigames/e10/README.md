# E10 피겨 암호 — 차준환 스케이터

게임은 아래 두 투명 PNG 시트만 불러옵니다. 개별 `skater_glide_01~04.png`,
`skater_jump_01~08.png`는 제공받은 원본으로 보관합니다.

| 파일 | 구성 | 사용 |
| --- | --- | --- |
| `skater_glide_4frame_sheet.png` | 2560×640, 640×640 셀 4칸 | 정지·활주 |
| `skater_jump_8frame_sheet.png` | 2560×1280, 640×640 셀 4칸×2줄 | 도약·공중 회전·착지 |

프레임은 왼쪽에서 오른쪽, 위에서 아래 순서입니다. 원본의 왼쪽 방향을 기준으로
오른쪽 이동 시 수평 반전합니다. 원본 셀 비율을 유지하고 공통 발끝 `(320, 608)`을
캐릭터 판정의 아래쪽에 맞춥니다. 점프는 1~2번 도약 → 3~6번 회전 → 7~8번 착지입니다.
공중에서는 회전 방향을 유지하고, 바닥에 닿으면 활주로 돌아갑니다.
바닥에서는 방향키를 누를 때만 다리 애니메이션을 재생합니다. 키를 놓으면 선 자세로
고정한 채 관성으로 미끄러집니다. 캐릭터 뒤의 원형 빛은 표시하지 않습니다.

등록 경로는 `../manifest.js`, 표시 크기와 동작 선택은
`js/archive/stages/e10_numberDecode.js`의 `E10_SKATER`와 `renderSkater`에서 관리합니다.
표시 크기는 52px에서 96px로 확대했습니다. 가로 조준 폭은 30px이며, 세로 판정은
커진 이미지의 머리~발 높이인 84px로 맞췄습니다. 마찰·가속·점프 수치와 암호 규칙은 유지합니다.
같은 파일명과 4×1 / 4×2 정사각 셀 구성을 유지하면 셀 해상도는 자동으로 읽습니다.
이미지를 바꾼 뒤 브라우저를 새로고침하세요. 캐시가 남으면 Ctrl+F5로 다시 불러옵니다.
발끝 위치나 자세 배치가 달라지는 이미지는 원점과 동작 순서를 다시 맞춰야 합니다.
빙판 자국과 착지 입자는 효과 설정을 따르며, 일시정지 중에는 애니메이션도 멈춥니다.
시트를 불러오지 못하면 기본 캐릭터로 플레이할 수 있습니다.

배경의 오륜 깃발과 밀라노 코르티나 2026 현수막, 목표 숫자를 덮는 얼음은 코드로 그립니다.
`E10_FROST.veil`은 전체 서리, `facet`은 얼음 조각의 불투명도로 숫자 해독 난이도를 조절합니다.
얼음은 정답과 무관한 고정 모양이며, 효과 설정을 꺼도 유지됩니다. 선택할 숫자 블록은 가리지 않습니다.
