# 9개 미니게임 개발 안내

실행 중인 게임은 아래 **e번호 + 이름.js** 파일입니다. `e1.mjs`~`e5.mjs`와 기존 물리 코어는 이전 버전 참고 자료이며 새 레지스트리와 실행 번들에는 포함되지 않습니다.

## 공통 흐름

- 메인 → 오프닝 → 중복 없이 뽑은 랜덤 5개 선택 → 게임 → 결과.
- 기본 제한시간은 모든 게임에서 20.26초입니다. 기존 누적 2:23 실패 제한 대신 게임마다 독립된 타이머를 사용합니다.
- 결과에는 **스테이지 선택 / 다시하기 · 기록 도전 / 메인으로**가 있습니다. 시간 초과도 결과에서 선택합니다.
- 선택 화면과 다시하기에서는 같은 5개를 유지합니다. 메인으로 돌아와 새 판을 시작하면 다시 추첨합니다.
- 성공한 5개를 모두 모아도 결과에서 기록 재도전과 선택이 가능합니다.
- 최고 기록은 클리어 시간 우선, 같은 시간이면 조작 횟수 우선으로 저장합니다.
- 게임 내 충돌/사망은 같은 시도입니다. e1 후퇴 시 장애물 상태, e2 사망 시 점프력, e3 붕괴 시 잔해와 속도, e6 충돌 시 중력, e9 실패 시 마찰을 유지합니다.
- 결과의 다시하기는 새 시도이므로 타이머와 페널티를 초기화합니다.

## 게임별 참고

- e1은 자동 전진이며 Space는 중력 반전입니다. 누를 때마다 플레이어가 바닥 벽과 천장 벽 사이로 떨어져 반대쪽 벽에 붙습니다. 금색 가시와 분홍색 블록은 플레이어와 같은 방향, 보라색 공중 블록은 반대 방향의 중력을 받으며 모두 움직입니다. 장애물 수직 속도는 최대 190px/s로 캐릭터 전진 속도 285px/s보다 느리고, 캐릭터가 먼저 반대쪽 벽에 도달합니다. 속도를 조정해도 장애물은 캐릭터 전진 속도의 80% 이하로 제한됩니다. 장애물 묶음은 390px 간격으로 10개이며, 너무 일찍 뒤집으면 따라온 장애물과 다시 만나고 너무 늦으면 벽을 벗어나기 전에 충돌합니다. 무충돌 골인은 약 16.32초입니다. 충돌하면 조금 후퇴하고 중력 방향과 모든 장애물의 위치/속도는 유지한 채 끌리는 쪽 벽에서 다시 시작합니다.
- e2는 A/D 좌우, W 체공/S 급강하, Space 착지 후 점프입니다. 왁뿌볼의 껍질에 점프마다 균열과 파손이 누적됩니다. 점프 속도는 740에서 매번 90%로 줄어 11번째 점프부터 최저 280이 됩니다. 천장은 열려 있고 높은 점프는 카메라가 따라갑니다. 발판 16개 중 파랑 3개는 승강 발판(초반 진폭 22px, 후반 10px), 주황 3개는 착지 후 0.55초 뒤 무너졌다가 1.4초 뒤 복구되는 발판입니다. 초반 간격은 105~115px, 중반 완충 구간은 65px입니다. 마지막 4단은 고정 계단으로 한 칸마다 20px 상승하고 간격은 90px입니다. 최저 점프력에서 W 없이 끝 6px 부근에서 뛰는 성공과 24px 일찍 뛰는 실패, 실제 D + Space 입력을 검증합니다. 도약 위치를 알려 주는 표시와 문구는 없습니다. 제한시간은 20.26초입니다. 사망 후에도 파손과 점프력을 유지하며 붕괴 발판은 체크포인트로 저장하지 않습니다. 다시하기는 공과 지형을 초기화합니다.
- e3은 두툼한 몸으로 버티기·팔 벌리기·만세 세 자세의 흰색 마네킹을 쌓습니다. 원래 팔다리 배치를 유지하고 사람 전체를 `tuning.dropAngles`에 따라 옆/대각선/거꾸로 돌려 제공합니다. 미리보기의 방향과 위치 그대로 낙하하고, 이후 머리와 몸통·팔다리를 합친 Matter 강체가 실제 접촉 위치, 질량중심, 관성, 마찰에 따라 회전하고 넘어집니다. 바닥/받침대부터 실제 접촉이 이어진 탑이 216 높이를 3초 연속 유지하면 성공합니다. 흔들림은 허용하지만 목표 높이 아래로 내려가거나 지지를 잃으면 카운트가 초기화됩니다. 공중의 낙하물은 높이에 포함하지 않습니다. 잔해는 동적인 받침으로 남고 속도는 유지됩니다. 탑이 높아지면 낙하 위치가 올라가며 시야가 넓어집니다.
- e4는 19×7칸(876×384px)의 랜덤 미로를 방향키/WASD로 자유롭게 탐색합니다. 7번 꺾는 주 경로와 갈림길·막다른 길, 한 화면에 보이는 출발점과 도착점을 제공합니다. 통로 폭은 84~112px, 벽 두께는 12px입니다. 방향키/WASD를 새로 누를 때마다 100px/s씩 누적되어 240→340→440…최대 1100px/s가 됩니다. 같은 방향도 뗐다 다시 누르면 가속하며, 길게 누르기와 키 자동 반복은 추가 가속을 만들지 않습니다. 상단 설명 줄을 없애고 미로를 y=88까지 확장했습니다. 정지해도 누적 속도를 유지하며, 속도선과 긴 잔상으로 가속을 표시하고 키를 놓으면 7200px/s²로 제동합니다. 실제 속도에 따라 저속(240px/s)은 약 4px/0.03초, 최고속(1100px/s)은 약 84px/0.15초 밀린 뒤 멈춥니다. 제동 중에도 벽 충돌이 적용되며, 다시 누르면 한 단계 빨라진 누적 속도로 이동합니다. 기본 20.26초, 벽 접촉마다 1초 차감(접촉 유지 중 중복 없음), 재도전 시 초기화합니다. 초록 출구에 도착하면 성공이며 QA 제한시간은 우선 적용됩니다.
- e5는 탄환을 당겼다 놓습니다. 목표물은 6개, 체력이 있으며 궤적 미리보기가 실제 발사 힘을 반영합니다. 탄환 수 제한은 없습니다. 약해져도 끝 목표에 도달하도록 최소 힘을 둡니다.
- e6의 무충돌 골인은 약 16.47초입니다. 새로 누를 때마다 중력 감소/상승 강화가 누적됩니다. 누르고 있는 동안 상승하며, 충돌하면 후퇴하고 중력은 유지합니다.
- e7은 금색이 당첨입니다. 드래그의 각속도를 최솟값/최댓값 사이로 제한한 후 실제로 감속합니다. 최종 추가 회전량을 한 바퀴 안에서 균일하게 정하여 영역 비율이 실제 확률이 됩니다. 별도 당첨 결과로 화면을 덮어쓰지 않습니다. 실패마다 1/2, 1/4, 1/6, 1/8…로 좁아집니다.
- e8은 처음부터 공중에서 시작하는 웹스윙 게임입니다. Space/클릭을 누르면 캐릭터 기준 가장 가까운 연결점에 거미줄을 걸고, 놓으면 현재 속도로 날아갑니다. 최초 연결은 시작 시 제공되며 첫 입력으로 줄을 잡은 뒤 놓을 수 있습니다. 연결 중에는 중력에 따른 진자 운동을 계산하고, 해제 후에는 수평 관성과 중력에 따른 포물선 운동을 유지합니다. 연결 중 중력은 1050, 자유 비행 중 중력은 1600에서 가속 배율에 따라 최대 2400까지 증가합니다. 이전보다 더 빠르게 아래로 끌려 내려가며 긴 체공으로 여러 건물을 지나치기 어렵습니다. 코스 길이는 14580px입니다. 무게감은 유지하고 24개 연결점 코스에서 두 구간을 줄였습니다. 새 연결점에는 스윙 방향을 유지하는 접선 가속을 적용하며 배율은 35%씩 올라 4번째 새 연결에서 최대 3배가 됩니다. 같은 연결점을 다시 잡으면 속도의 접선 성분만 남으며 추가 가속은 없습니다. 앞뒤·높이·사거리·방문 이력으로 연결을 제한하지 않으며 방금 놓은 연결점도 즉시 다시 잡을 수 있습니다. 길이 0인 줄을 피하기 위해 중심 1px 이내의 점만 제외합니다. 연결점 간격 660px, 총 22개이며 엠파이어 빌딩·크레인·일반 건물을 서로 다른 높이로 배치합니다. 건물은 배경 평면으로 착지/충돌하지 않으며 아래로 추락하면 마지막 연결점의 공중 스윙으로 복귀합니다. 방문 이력과 가속 배율은 추락 후에도 유지합니다. 마지막 공중 게이트를 실제로 통과해야 성공합니다. 여러 입력 경로에서 무추락 완주 약 15.7~16.2초, 기본 제한시간은 20.26초입니다. 카메라는 연결점과 캐릭터를 함께 담도록 확대율을 조정합니다. 그림 교체는 [e8 에셋 가이드](../../../assets/minigames/e8/README.md)를 참고하세요.
- e9는 돌을 당겼다 놓습니다. 돌 전체가 금색이 아닌 분홍 과녁 안에 멈추어야 성공하며, 실패한 돌은 지우고 같은 시도에서 더 미끄러운 얼음에 새 돌을 놓습니다.

## 코드 분리

`index.mjs`는 ID 등록만, `minigame-kit.js`는 도형/에셋 표시 도구만 담당합니다. 게임별 상태는 새 `scene.state`와 게임이 생성한 씬 필드에 있습니다. 게임 파일끼리 서로를 참조하지 않습니다.

공통 `../game.mjs`가 입력, 120Hz 물리 시간, 20.26초 타이머, 결과 이벤트를 담당합니다. 게임의 `build/update/render` 및 선택적인 `action/press/pointerDown/pointerMove/pointerUp/cancelInput/timeout/dispose` 훅을 호출합니다. Phaser의 기존 속성과 겹치지 않도록 효과음은 `this.sfx()`를 사용합니다.

전환 시 입력/드래그/타이머/트윈/표시 객체를 정리합니다. 사람 쌓기의 Matter 월드는 `dispose`에서 파기합니다. 일시정지, 창 포커스 이탈, 드래그 취소는 발사하지 않고 입력을 해제합니다.

이름과 조작 설명은 `../../content/minigame-catalog.js`, 랜덤 선택은 `../run-state.mjs`, 최고 기록은 `../records.mjs`에서 관리합니다.

## 밈 에셋 연결

`assets/minigames/manifest.js`의 역할별 `null`을 이미지 경로로 교체합니다. 예:

```js
e3: { person: 'assets/minigames/e3/person.webp' }
```

`player`, `obstacle`, `person`, `target`, `projectile`, `prize`, `weight`, `stone` 역할은 manifest를 참고하세요. 투명 배경에 여백이 적은 이미지를 권장합니다. 이미지가 없거나 로딩되지 않으면 기본 캐릭터 도형을 사용합니다. 이미지 교체는 표시만 바꾸며 물리 판정을 변경하지 않습니다.

e3은 `person_crouch`, `person_wide`, `person_reach`로 자세별 이미지를 적용합니다. e3 이미지의 중심, 여백, 크기는 [e3 에셋 가이드](../../../assets/minigames/e3/README.md)를 따릅니다. 그림의 팔다리 위치를 바꾸면 충돌 형태도 함께 조정하세요. 파일을 직접 여는 환경은 Canvas/HTML 이미지 로더, 웹 서버에서는 Phaser AUTO 렌더러를 사용합니다.

## 실행과 검증

원본을 수정한 뒤 실행 번들을 갱신합니다. `game-classic.js`는 직접 수정하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-archive-classic.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/minigame-browser.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/e3-physics-browser.ps1
```

`index.html`을 직접 열어 플레이할 수 있습니다. 검증은 설치된 Chrome의 headless 모드에서 실제 Phaser 씬을 사용합니다. 브라우저 경로는 테스트 스크립트의 `$chrome`에서 변경합니다.

검증 범위: 9개 로딩, 랜덤 5개 중복 방지, 20.26초 종료, 성공 경로, 페널티 유지, 정지/전환 정리, 룰렛 당첨/꽝 판정, 최고 기록, 결과의 3개 버튼, 실제 키보드와 축소된 모니터의 마우스 드래그. 화면 캡처는 `tests/.artifacts/`에 저장됩니다. 자동 입력 성공 경로는 플레이 난이도를 인간 대상으로 검증한 결과를 의미하지 않으며 세부 밸런스는 플레이테스트 후 조정합니다.

기존 `archive-*-check`와 `stage-split-baseline.json`은 이전 5개 게임용 회귀 자료입니다. 새 게임 검증에는 위 `minigame-browser.ps1`을 사용합니다.
e3 전용 검증은 중심 착지/가장자리 전도/팔다리 사이 빈 공간/잔해 위 재쌓기/공중 높이 제외/누적 속도 유지/에셋 회전 중심/로컬 이미지 로딩/씬 정리를 확인합니다. `tests/.artifacts/e3-tower.png`, `e3-topple.png`에서 쌓인 탑과 낙하 충돌로 넘어진 모습을 확인할 수 있습니다.
