# RECORD 03 — 탄성 과잉

클릭 발사와 전방위 반사를 좌우 조작 / 자동 바운스 방식으로 교체했다.
20.26초 타이머와 부분·완전 복구 저장 방식은 기존 시스템을 사용한다.

- A/D 또는 방향키로 좌우 이동한다. 키를 놓으면 가로 이동이 멈춘다.
- 최초 바운스 높이는 72px. 바닥이나 발판에 착지할 때마다 다음 높이가 24px씩 증가하며 216px에서 제한된다.
- 가로 속도는 185px/s로 일정하다. 벽 옆면은 가로 이동을 막고, 천장은 상승 속도를 흡수한다. 두 접촉 모두 탄성을 증가시키지 않는다.
- 시작 바닥 이후에는 폭 22~26px의 고립된 발판을 연결한다. 오른쪽→왼쪽→오른쪽으로 방향을 바꾸는 상승 발판 세 개 → 낮은 착지 발판 두 개 → 천장 아래 발판 → 폭 28px의 도착 지점 순서다. 바닥으로 추락하면 실패한다.
- 가장 어려웠던 버전과 완화 버전의 중간으로, 각 발판을 원래 중심 기준 좌우 2px씩 넓혔다. 높이, 탄성, 이동 속도와 최소 착지 겹침은 유지한다.
- 초반 상승 단차는 62/88/112px로, 해당 바운스 높이보다 8~10px만 낮다.
- 착지에는 최소 14px의 겹침이 필요하다. 가장자리에 살짝 걸치거나 가로 입력을 계속 누르면 추락한다.
- 네 번째 발판 위의 조각은 제자리 바운스를 두 번 더 쌓아야 닿는다. 커진 바운스로 후반의 좁은 착지와 낮은 천장을 통과해야 한다.
- 기본 진행 경로에서는 조각을 얻지 않는다. 조각을 얻은 후에도 코어에 도착해야 완전 복구된다.
- 정답 경로와 점프 위치 표시는 없다. 바닥 틈과 천장 밑면에만 위험 색상을 사용한다.

실제 물리 코어는 `js/archive/bounce-core.mjs`에 있고, 장면과 자동 검증이 이를 공유한다.
`tests/archive-bounce-check.mjs`는 40/60/120Hz 기본·조각 경로, 천장·벽 접촉, 높이 제한, 추락을 검증한다.
브라우저 검증은 실제 입력 연결, 두 복구 결과, 재시작 초기화도 확인한다.
자동 경로의 성공은 통과 가능성 검증이며 사람의 체감 난이도는 플레이 후 조정한다.
