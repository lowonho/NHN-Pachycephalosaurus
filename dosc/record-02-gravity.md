# RECORD 02 — 중력 타워

하나의 정답 계단 대신 직행 경로, 중간 발판을 거치는 경로, 왼쪽으로 돌아 조각을 얻는 경로를 제공한다. 출발 바닥 외에 9개의 발판을 두며 전부 밟을 필요는 없다. 발판 끝 표시, 순서 번호, 점프 방향 안내와 HUD의 조각 경로 힌트는 없다. 목적지 비콘과 수집 상태는 유지한다.

- 직행 경로는 기존 좁은 발판을 4회 점프로 연결한다.
- 중간 발판을 이용하면 5회 점프로 기본 목표에 도달한다. 추가 조작으로 중력이 더 강해지는 대가가 있다.
- 조각은 왼쪽 우회 발판 표면 위에 놓인다. 공중에서 획득 후 급히 돌아오는 대신 발판에 도달해 자연스럽게 획득하고 상단으로 합류한다. 검증 경로는 6회 점프다.
- 출구 외 발판 폭을 26~40px로 축소했다. 출구는 60px이며 도착 지점도 코스에 맞춰 옮겼다.
- 우측 아래 복귀용 발판을 제거하고 바닥은 출발 구역의 145px만 남겼다. 다른 발판에도 착지하지 못하고 화면 아래로 떨어지면 즉시 `RECORD LOST`가 된다. 자동 재배치하지 않는다. 화면 아래 붉은 선으로 낙하 경계를 표시한다.
- 이동 속도 190px/s, 도약 속도 430px/s. 중력은 720부터 입력마다 80씩 증가하고 1040에서 멈춘다. 20.26초 제한과 기존 물리 수치를 유지한다.

`gravity-core.mjs`에서 맵·물리를, `fragments.mjs`에서 조각을 관리한다. `node tests/archive-gravity-check.mjs`는 40/60/120Hz에서 세 경로를 실제 이동 함수로 검사한다. 중력 상한에서도 세 경로가 가능하고, 모든 발판이 필수는 아니며, 기본 경로에서는 조각이 수집되지 않는지 확인한다. 자동 조작 시간은 직행 약 4초, 중간 경유 약 5초, 조각 우회 약 6초이며 실제 첫 플레이 시간을 뜻하지 않는다.
